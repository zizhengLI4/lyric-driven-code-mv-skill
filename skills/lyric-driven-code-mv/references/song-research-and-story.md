# 歌曲考据与故事转译

适用：新作或重写叙事时，用户没有指定人物、剧情或创作方向中的一项或多项。目标不是给歌曲写百科，而是把可核验的背景转成有明确因果、能落实到镜头的原创故事。

## 先保留用户已经给出的内容

| 用户提供 | 必须保留 | 只补缺失部分 |
|---|---|---|
| 只有歌名或音频 | 歌曲、录音版本和用户给定限制 | 歌曲考据、人物、故事、连续分镜 |
| 歌曲 + 人物 | 人物身份、外观、关系与明确设定 | 背景考据、故事与分镜；不改人物 |
| 歌曲 + 剧情 | 事件、关键动作、结局与限制 | 背景考据、人物功能位与分镜；不改结局 |
| 歌曲 + 人物 + 剧情 | 全部已确认设定 | 只补分镜和实现，不擅自重写 |

不要求用户先编故事。只有歌名/版本歧义会实质改变考据或剧情时，才询问需要区分的版本；不要把开放式的“你想要什么故事”当作默认澄清。

## 联网检索与核验

1. 先锁定具体作品：歌名、艺人、发行/专辑、词曲作者、录音版本，区分原唱、翻唱、采样或改编。仅凭同名搜索结果不要认定身份。
2. 搜索创作缘起、作者或演唱者对作品的公开讲述、相关个人经历，以及歌词明确涉及的时代、地点、人物、方言和器物。使用原文关键词补搜；搜索摘要只用于发现线索，不能作为已核实证据。
3. 优先打开可追溯的一手材料：创作者/艺人访谈、官方专辑文案、唱片公司资料、作者公开记录；用可信的同期报道、档案或专业资料交叉核对重要主张。记录来源实际支持了什么，不从标题推断正文未说的内容。存在冲突时并列说明，不强行选边。
4. 对每项素材判断它和这首歌的关系：作品身份、明确创作意图、艺人经历、歌词可见线索、外部历史背景。只有来源明确建立了“经历—创作”联系，才把经历称为歌曲背景或创作动机；艺人的人生不自动等于歌词叙述者的人生。翻唱者的经历也不自动成为原作背景。
5. 不上传用户的私人录音、未发行歌词或其他未公开材料来搜索。用户禁止联网、联网能力不可用或检索无结果时，明确说明；不伪称已查证，也不以虚构引文填空。

## 给证据做标记

在工程 `research.md` 记录来源和创作转译。每条内容标记为：

- **事实（fact）**：来源直接陈述且对应具体作品/人物；记录来源编号。
- **推断（inference）**：由若干已记录事实推得，但来源没有直接这么说；写出推理依据，不能换成事实语气。
- **创作（creative）**：虚构角色、事件、对白、道具、结局或视觉隐喻；明确不是现实人物经历。

建议用紧凑的 Markdown 表格保持可读和可追溯：

| ID | 类型 | 主张/创意 | 来源 ID 或依据 | 转成的故事/镜头 |
|---|---|---|---|---|
| C1 | fact | 创作者在访谈中说明作品写于离开家乡后 | S1 | 世界背景，不把主角写成创作者 |
| I1 | inference | 离开与无法告别可能是作品的重要张力 | C1 + 歌词段落 | 主角想寄回一件旧物 |
| V1 | creative | 虚构主角在副歌把钥匙寄回旧居 | 原创演绎 | `s02-send-key` |

来源表至少记录 `S1` 这样的 ID、标题、发布者/作者、发布日期（能查到时）、URL、检索日期（`YYYY-MM-DD`）、材料类型，以及支持的主张 ID。不要只留 URL 而不说明它证明了什么。校验器若未显式支持该笔记结构，不得声称它已经自动验证研究真实性。

## 从考据到连续故事

1. 用一两句概括歌曲中可确认的核心问题和情绪变化；引用事实时能回指来源，不能确认的动机留作推断或标为未知。
2. **先生成主角外观卡，再构思其他部分。** 依据歌曲背景、歌词意象、人物身份和用户已给的形象约束，先确定主角轮廓、衣装、配色、识别物和像素简化；外观卡应能解释主角的欲望、代价或行动。用户已给人物外观时只补缺失细节，不覆盖原设定。
3. 再从主角的欲望与外观构思阻碍、配角/见证者和世界规则，确定主角要什么、必须做何选择，以及选择留下什么后果；不要先堆配角和场景再把主角随手塞进去。
4. 允许原创角色转译背景，不要求复刻真实艺人。例如资料只支持“创作发生在迁居之后”，可以写虚构人物整理旧屋、尝试寄回钥匙、最后选择留下；钥匙和选择是创作，不是艺人轶事。
5. 按真实歌词/音乐段落组织 3–5 个阶段；每阶段写“目标 → 行动 → 反馈 → 结果”，再拆成有连续性的 `scenes[]`。无歌词副歌/间奏也沿主角的目标线推进；重复副歌应增加新信息、视角或代价，让前一次选择改变后续状态。
6. 让研究主张落到镜头：在 `research.md` 中记录“来源/主张 → 采用或不采用的故事元素 → `scene.id`”。事实可以定背景，不需要每个镜头都复述事实；虚构镜头不能被交付文案包装成真人经历。

若没有可信背景材料，就依据歌词可见意象和音乐情绪写原创故事，并明确说“背景未核实，以下为原创演绎”。若用户只要分镜、报告或指定片段，就只交付该阶段；需要成片时继续主 Skill 中的样片、渲染和验收流程。

## 反面清单

- 把搜索结果摘要当作来源，或用百科转述替代可打开的原始访谈。
- 因为歌词使用第一人称，就断言这是歌手亲历。
- 把艺人一生中真实发生过、但未证实与此歌相关的事件写成创作缘起。
- 把虚构角色、道具或结局混入事实段落，不标改编。
- 把研究摘要当成故事，成片里只有标题/引用文字，没有角色行动和后果。
- 为了追求“完整考据”而停止创作；缺失处应透明标注，再用原创内容补足。

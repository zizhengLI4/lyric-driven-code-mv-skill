# 参考片取证记录

参考片分析先记录来源、取证日期、样本范围、采样方法和文件哈希。把观察分成三层：

1. **可见事实**：装置、构图、HUD、字幕、材质变奏、章节牌和镜头区间。
2. **可复现测量**：视频时长、分辨率、抽帧时间和出现次数。
3. **推断**：可能的实现框架、缓动曲线、粒子生命周期和音画同步。

均匀抽帧适合建立横向样本台账；它不能证明逐帧动效或真实节拍。没有音频轨道分析和原始工程时，BPM、切点对拍和 Remotion/Canvas/AE 归属均保持未知。若要升级结论，补做音频分析、逐帧抽查或取得作者工程说明，并在记录中标注新增证据。

建议台账字段：`作品 id`、`时长`、`取证时间`、`分辨率`、`采样点`、`device`、`chapters`、`hud`、`materialVariant`、`事实`、`推断`、`限制`。
